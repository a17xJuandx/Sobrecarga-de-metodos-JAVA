# Programación Orientada a Objetos (Java)
## Sistema de Sobrecarga de Métodos (Ejercicio2)
#### Universidad Nacional de Colombia

---

Este repositorio contiene el desarrollo del programa **Ejercicio2**, enfocado en la aplicación de los principios de la **Programación Orientada a Objetos (POO)** en **Java**, específicamente demostrando el concepto de **sobrecarga de métodos** (*method overloading*). El programa ilustra cómo definir múltiples métodos con el mismo nombre pero con diferentes firmas (tipos y cantidad de parámetros) para procesar operaciones aritméticas de forma flexible.

---

## Contenido del Proyecto

El desarrollo incluye clases estructuradas y métodos para gestionar las siguientes operaciones:

* **Clase Suma:** Modela un componente aritmético que implementa múltiples versiones sobrecargadas del método `Sumar`, permitiendo operar eficientemente con diferentes tipos de datos numéricos y cantidades de argumentos (como dos o tres valores de tipo `int` y `double`).
* **Clase Principal (Ejercicio2):** Coordina la ejecución del programa, instanciando un objeto de tipo `Suma` y realizando llamadas directas a las distintas variantes del método sobrecargado para verificar los resultados obtenidos y desplegarlos ordenadamente por consola.

---

## Especificaciones de Ejecución

* **Entorno:** Desarrollado para su compilación y ejecución en entornos compatibles con **Java (JDK 8 o superior)**, como NetBeans, IntelliJ IDEA o Eclipse.
* **Requerimientos:** No se requieren librerías externas adicionales; el proyecto utiliza exclusivamente las estructuras estándar de Java bajo el paquete `Ejercicio2`.
* **Estructura:** El código está organizado para evidenciar las buenas prácticas en polimorfismo en tiempo de compilación mediante la reutilización de nombres de métodos con firmas diferenciadas.
